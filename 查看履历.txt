bash 语句
═══════════════════════════════════════════════════════════════
命令	作用
git add .	暂存所有修改
git commit -m "注释"	提交到本地仓库
git push	推送到云端（GitHub）

命令	作用	使用场景
git status	查看当前状态（哪些文件改了）	每次修改前先看一下，心里有数
git pull	从云端拉取最新代码	B电脑改了并push后，A电脑用这个同步
git log	查看提交历史	想回顾之前改了什么
git reset --hard（代码损坏简单粗暴回退某个历史版本，已经会用）
git clone 地址	从云端下载完整项目	新电脑第一次拿代码



场景一：A 电脑开发完，B 电脑要同步
A 电脑（提交）：

bash
git add .
git commit -m "添加了XX功能"
git push
B 电脑（获取最新）：

bash
git pull
场景二：B 电脑开发完，A 电脑要同步
B 电脑（提交）：

bash
git add .
git commit -m "修复了XX问题"
git push
A 电脑（获取最新）：

bash
git pull
📌 你最需要记住的
除了那三句，再加这一句就够了：

bash
git pull   # 从云端拉取别人（或另一台电脑）的最新修改
📌 完整日常流程
bash
# 1. 开始工作前，先拉取最新代码（防止冲突）
git pull

# 2. 修改代码...

# 3. 提交并推送
git add .
git commit -m "修改说明"
git push

                    FV 插件 安装使用说明
═══════════════════════════════════════════════════════════════

【适用版本】
  Excel 2010 / 2013 / 2016 / 2019 / 2021 / Office 365
  支持 32 位和 64 位

─────────────────────────────────────────────────────────────

【安装步骤】

  1. 安装运行环境（如已安装可跳过）
     ─────────────────────────────────────────────────────
     双击运行 “运行环境.exe”，按提示完成安装。
     包含组件：.NET Framework 4.0 + VSTO Runtime

     ★ 特别说明：
        ● Excel 2013 及以上版本：VSTO Runtime 已内置，可跳过此步
        ● Excel 2010 用户：必须安装此环境，否则插件无法运行

  2. 安装 FV 插件
     ─────────────────────────────────────────────────────
     双击运行 “setup.exe”，按提示完成安装。

  3. 启用 FV 插件
     ─────────────────────────────────────────────────────
     打开 Excel → 文件 → 选项 → 加载项
     在“管理”下拉框中选择“COM 加载项” → 点击“转到”
     勾选 “FV” → 点击“确定”

─────────────────────────────────────────────────────────────

【注意事项】

  ⚠ 安装前请关闭所有 Excel 窗口
  ⚠ 安装前请暂时退出杀毒软件（360、腾讯管家、金山毒霸等）
  ⚠ 如遇杀毒软件拦截，请选择“允许”或“添加信任”

─────────────────────────────────────────────────────────────

【常见问题】

  Q1：安装后 Excel 加载项列表中找不到 FV？
  A1：检查是否已安装运行环境；确认 Excel 版本是否为 2010 及以上；
      若在“COM 加载项”中仍找不到，请以管理员身份重新运行 setup.exe

  Q2：插件加载失败或报错？
  A2：确认 .NET Framework 4.0 和 VSTO Runtime 已正确安装；
      尝试重启 Excel 或重启计算机

  Q3：Excel 启动时提示“无法加载 FV”？
  A3：重新运行 setup.exe 修复安装

─────────────────────────────────────────────────────────────

【技术支持】

  如有其他问题，请联系技术支持并提供以下信息：
  ● Windows 版本（Win + R → 输入 winver）
  ● Excel 版本（文件 → 账户 → 关于 Excel）
  ● 错误提示截图（如有）

─────────────────────────────────────────────────────────────

                       感谢使用 FV 插件！
